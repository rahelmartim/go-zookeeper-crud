ZooCRUD

A CRUD shell for ZooKeeper, written in Go. ZooKeeper stores data in a tree of znodes, with paths like /zoo/lion. Type commands in the terminal and watch the tree change.

View on GitHub

This demo runs the same command code as the CLI, on an in-memory tree that follows the ZooKeeper rules. The CLI also connects to a real ZooKeeper server.

zoocrud — in-memory

      ZooKeeper rules

      • Every path starts at the root /.
      • The parent of a new node must exist.
      • Every update adds 1 to the version of the node.
      • A node with children cannot be deleted. DELETEC deletes the children first.

      Run it with a real ZooKeeper

      # start ZooKeeper
docker run --rm -p 2181:2181 zookeeper:3.9
# start the shell
go run ./cmd/zoocrud
